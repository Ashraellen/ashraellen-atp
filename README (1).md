# ATP Public Protocol Templates

These templates are intentionally public-facing abstractions. They are designed to make the method reproducible without requiring private chat archives, private prompts, or model-specific conversational memory.

- `bootstrap-template.md` — initialize source, authority, constraints, and workflow state
- `glossary-template.md` — record authorized terminology decisions
- `unit-protocol-template.md` — process one stable literary unit
- `validation-checklist.md` — validate before canonical acceptance
- `handoff-template.md` — transfer authorized state across sessions, operators, or tools
