# Ashraellen Transcreation Protocol v1.0.0

This is the first stable public release of the Ashraellen Transcreation Protocol (ATP), a human-directed methodology for AI-assisted literary transcreation.

## Central principle

> **Success is measured by how well the system prevents the human from losing themselves.**

ATP is designed around a simple boundary: AI may absorb complexity, but canonical authority remains human.

## Included

- methodology and scope;
- Human–AI Responsibility Model;
- workflow architecture;
- validation model;
- reproducibility model;
- reusable project, glossary, unit, validation, and handoff templates;
- documented limitations and failure modes;
- a rights-safe synthetic demonstrator;
- a framework for future bounded MONOLITH case studies.
