# Ashraellen Transcreation Protocol v1.1.0

This release strengthens ATP as a public research-facing methodology and makes the repository easier to understand, apply, cite, and archive.

## Central principle

> **Success is measured by how well the system prevents the human from losing themselves.**

ATP remains built around a simple boundary:

**AI may absorb complexity. Canonical authority remains human.**

## What changed

- expanded the README into a clearer public entry point;
- added release, license, and citation badges;
- added a Mermaid architecture diagram;
- added explicit design principles;
- added a minimal usage path linked to reusable protocol templates;
- clarified model independence and reproducibility;
- added a focused roadmap for real-world evidence, archival releases, and authorship-continuity research;
- synchronized `CITATION.cff` with version `1.1.0`.
