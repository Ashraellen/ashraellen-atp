# Public Validation Checklist

Use before a unit is accepted as canonical target text.

## Source
- [ ] Correct source language and version confirmed.
- [ ] Unit boundary confirmed.
- [ ] No unauthorized intermediate translation used.
- [ ] No omission or duplication detected.

## Meaning
- [ ] No meaning omitted.
- [ ] No explanation added merely for convenience.
- [ ] Agency, causality, chronology, and ambiguity preserved where intended.
- [ ] Metaphor has not been replaced by summary.

## Terminology
- [ ] Locked terms match current glossary.
- [ ] Capitalization/register conventions preserved.
- [ ] No accidental synonym drift.

## Voice
- [ ] Density and rhythm remain functionally consistent.
- [ ] Deliberate roughness has not been polished away.
- [ ] Irony/humour has not been normalized into safer prose.
- [ ] Philosophical pressure has not become explanation.

## Dialogue
- [ ] Speaker remains identifiable by function and register.
- [ ] Emotional temperature preserved.
- [ ] Character voices have not converged into generic neutrality.

## Structure
- [ ] Headings and ordering correct.
- [ ] Paragraph and fragmentation choices preserved unless explicitly justified.
- [ ] No structural simplification introduced silently.

## Continuity
- [ ] Candidate is consistent with prior authorized decisions.
- [ ] New decisions affecting future work are recorded.
- [ ] Any exception is explicit rather than accidental.

## Authorship continuity
- [ ] The author can still recognize the target as their own work.
- [ ] Fluency has not displaced identity.

## Final gate
- [ ] Human authority has ACCEPTED the unit or recorded an approved exception.
- [ ] State and index have been updated if required.
